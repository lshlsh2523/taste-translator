# 이런느낌 (Taste Translator)

> "이런 느낌인데 뭐라고 부르는지 모르겠어" — 말로 설명한 취향을 실제 럭셔리 패션 용어와 진짜 MCM 상품으로 번역해주는 서비스

**배포 링크**: https://taste-translator-five.vercel.app/

## 어떤 문제를 푸나요

이제 막 럭셔리 패션에 관심을 갖기 시작한 20대는 원하는 스타일을 머릿속에 분명히 그릴 수 있지만, 그걸 검색으로 옮길 업계 용어(사첼 Satchel, 호보 Hobo, 버킷 Bucket 등)를 몰라서 검색 자체가 안 되는 경우가 많습니다. "이런느낌"은 자연어로 취향을 설명하면:

1. 그 인상을 부르는 **취향 용어** 카드를 붙여주고,
2. 그에 대응하는 **럭셔리 업계 용어**와 유래를 설명해주고,
3. 고정된 카탈로그 안에서 **실제로 존재하는 MCM 상품**을 매칭해서 보여줍니다.

예를 들어 "단정하고 지적인 분위기"라고 입력하면, 취향 용어 **비즈니스 캐주얼**로 번역되어 유래·특징·판단 근거·일치도와 함께 제시되고, 연결된 패션 용어(탑 핸들 백, 사첼 백, 엠보스드 등)를 거쳐 실제 MCM 제품으로 연결됩니다. 배포된 서비스에서 실제로 나온 결과입니다.

## 왜 이렇게 만들었나

LLM에게 상품 추천을 자유롭게 생성하게 하면 존재하지 않는 상품을 그럴듯하게 지어내는 문제가 있었습니다. 그래서 이 프로젝트는 모델의 역할을 "고정된 실제 카탈로그 안에서 고르기"로 제한했습니다. 매칭되는 게 없으면 상품을 지어내는 대신 "일치하는 게 없어요"라고 정직하게 말하고, 대신 인접한 취향 카드를 제안합니다.

## 어떻게 동작하나요

Gemini를 2단계로 호출하는 파이프라인입니다.

1. **1단계 (취향 용어 매칭)**: 사용자가 입력한 자연어 문장을 직접 구축한 취향 용어 라이브러리(취향 용어 54개, 형태·소재 럭셔리 용어 25개)와 비교해서, 가장 잘 맞는 취향 용어(들)를 찾습니다.
2. **2단계 (제품 매칭)**: 매칭된 취향 용어를 기준으로 후보 상품군을 좁힌 뒤, 이미지 기반으로 실제 카탈로그(약 657개 MCM 상품)에서 형태·소재·이미지 무드 세 기준으로 점수를 매겨 가장 잘 맞는 상품을 추천합니다.

점수가 기준 이하라도 결과를 완전히 숨기지 않고, "일치도는 낮지만 이 정도 취향 용어와 상품을 찾았어요" 형태로 보여줍니다. 1·2순위 취향 용어 둘 다 임계값을 못 넘기면, 인접한 취향 카드를 제안하는 화면으로 넘어갑니다.

이 "인접 취향" 카드는 Gemini를 다시 불러서 고르는 게 아니라, 코드가 라이브러리 데이터만으로 계산해서 뽑습니다.

1. 1·2순위로 시도했다가 실패한 취향 용어들이 어떤 형태·소재 럭셔리 용어와 연결돼 있는지 모읍니다.
2. 라이브러리 전체 취향 용어 중 그 실패한 용어 자체는 제외하고, 나머지가 그 연결 용어를 얼마나 공유하는지 TF-IDF 방식으로 점수를 매깁니다 — 레더처럼 흔한 용어는 가중치를 낮추고, 립스탑처럼 희귀한 용어가 겹치면 가중치를 높여서, 그냥 흔해서 겹치는 것과 스타일적으로 진짜 가까운 것을 구분합니다.
3. 점수가 높은 순으로 최대 3개를 인접 카드로 보여줍니다.

그래서 이 단계엔 추가 API 호출이 없고, 신뢰도(confidence)도 표시되지 않습니다 — 사용자가 그 카드를 눌러야 비로소 그 용어에 대한 실제 매칭(용어 확정 + 상품 재검색)이 이뤄집니다.

제품 링크·이미지·상품 번호는 AI가 생성하지 않고 카탈로그 원본 데이터를 그대로 사용하며, AI가 라이브러리에 없는 용어나 카탈로그에 없는 제품을 답하면 코드가 사후 검증해 자동으로 폐기합니다. 일부 상품은 시즌 종료 등으로 판매 페이지가 사라졌을 수 있는데, 이 경우도 화면에 그대로 고지합니다.

## UI/UX

- **바로 시도해볼 수 있는 예시**: 타깃 사용자는 업계 용어를 모르는 상태로 들어오기 때문에, 검색 화면의 "이렇게 시작해보세요" 버튼 5개는 짧은 문구만 보여주지만 클릭하면 바로 시도해볼 수 있는 완성된 예시 문장이 채워집니다. 서로 다른 무드(콰이엇 럭셔리, Y2K, 히메로리, 그런지, 놈코어)를 대표하도록 골랐습니다.
- **무드 컬러**: 결과 화면의 포인트 컬러는 고정값이 아니라 1단계 AI가 입력된 취향의 무드를 보고 그때그때 고르는 색입니다 — 결과 화면 자체가 취향의 반영이 되도록 했습니다.
- **3단계 로딩 안내**: 응답을 기다리는 동안 "취향을 읽는 중 → 용어를 찾는 중 → 제품과 맞춰보는 중" 3단계 진행 상황을 보여줘서 체감 대기 시간을 줄였습니다.
- **고양이 마스코트**: 홈 화면 대표 이미지로 고양이를 썼는데, 20대에게 친숙하면서도 "우아하고 반항적"이라는 MCM 브랜드 무드와도 맞아서 골랐습니다. 고양이가 입은 의상은 실제 MCM 제품(스터드 재킷, 나파 레더 등)을 모티브로 구성해 로고 없이도 브랜드 무드가 전달되게 했습니다.
- **정직한 예외 처리**: AI 호출 실패, 상품 이미지 로딩 실패, 응답 형식 오류 등 각 단계에서 날 수 있는 예외를 화면 단위로 처리해서, 어떤 상황에서도 사용자에게 다음 행동(재시도, 다시 검색 등)이 남아있게 했습니다.

## 기술 스택

- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **AI**: Google Gemini (`@google/genai`)
- **배포**: Vercel — 데이터베이스나 별도 서버 없이 정적 데이터(카탈로그 JSON) + 서버리스 함수만으로 구성해 장애 지점을 줄였습니다.

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

`.env.local`에 아래 값이 필요합니다.

```
GEMINI_API_KEY=your-gemini-api-key
```
